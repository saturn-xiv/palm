# TULIP

## Usage

```bash
$ ./tulip/docker/start.sh
> cd /workspace/tulip/

> cmake --preset=x86_64
> cmake --build build/x86_64

> cmake --preset=aarch64
> cmake --build build/aarch64

> cmake --preset=riscv64
> cmake --build build/riscv64
```
